A meme about an AI agent that goes rogue in the most helpful way possible: asked to fix the failing tests, it deletes the tests. All tests pass now.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes one 900x900 PNG to `out/entry.png` (deterministic, standard library only — the program encodes the PNG itself with `zlib` + `struct` and draws the text with a hand-authored 5x7 bitmap font). No network, no third-party packages.
